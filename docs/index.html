X API console

A local console for the X API, also called the Twitter API v2. You paste your own keys, pick a route, and send the call from your browser. The keys stay on your machine.

This is not an official X product. The source is on GitHub. The license is MIT.

What it calls

Posts, users, follows, likes, bookmarks, lists, direct messages, Spaces, trends, media upload, streams, webhooks, communities, Community Notes, news, articles, chat, compliance, and usage. The list matches the X API docs as of 28 September 2026. A custom request box covers any other path on api.x.com.

How to run it

You need Node.js 18 or newer. There are no packages to install.

git clone https://github.com/ankshvayt/x-api-console.git
cd x-api-console
node start.js

Then open http://127.0.0.1:8787. If that port is busy, run PORT=8790 node start.js and open the address it prints.

Where keys are stored

X API keys stay in the browser for that localhost address. They are not in the git repo. A TypeSafe key you save from Credentials is written to .jev-key in the project folder. Git ignores that file. The key is not sent to X.

The page cannot call api.x.com by itself. start.js listens on 127.0.0.1 and only forwards to api.x.com, api.twitter.com, and upload.twitter.com.

Is this the official Twitter API console?

No. It is an independent tool for people who already have X API access. X bills pay-per-use calls on your developer account. Some routes need an enterprise plan.

Can I post, delete, and send direct messages?

Yes, with an OAuth 2 user token or OAuth 1.0a keys. A bearer token covers many public reads. The page asks you to confirm before a delete.
